# مورد: العرض التشغيلي الافتراضي

واجهة محلية تقرأ `GET /api/state` فقط، وتعرض خزانات ومعدات وتدفقات محرك المنشأة الافتراضية. لا تنشئ جلسة ولا ترسل أمر تشغيل. تحكم العملية في `/#plant`؛ الصفحة المستقلة في `/plant3d/index.html`.

التدفقات والحجوم والقراءات لا تُحسب في المتصفح. حركة النقاط في الأنابيب اتجاه بصري فقط، وتتوقف عند توقف ساعة المحاكاة أو فقد التحديث. موضع الصمام يستند إلى feedback، منفصلًا عن طلب المتحكم. المصدر العام أو جلسة مختلفة أو snapshot غير افتراضي يمسح حالة العرض. نموذج الذكاء البحثي لا يدير هذا التوأم، ولا يوجد ربط بأجهزة حقيقية.

المشهد الهندسي السابق `/viewer/` مستقل ولم يتغير. هذه هندسة توضيحية لتوأم بخزانين 3000 لتر، وتغذية مفترضة 15 م³/يوم واسترداد حجمي مفترض 80%؛ ليست رسومات تصنيع أو قياسات منشأة فعلية.

من جذر المشروع:

```sh
npm run build --prefix mawrid-system/plant3d
node --test mawrid-system/plant3d/test-*.mjs
```

يستخدم البناء Three.js وVite وخط IBM Plex Sans Arabic الموجودة محليًا في `mawrid-final/node_modules`، ويكتب فقط `mawrid-system/client/plant3d/`. لا تنزيل أو CDN. تراخيص المكتبات والخط مرفقة في `public/licenses/` وتُنسخ إلى البناء. `test-review.mjs` مراجعة مستقلة لمسار القراءة والاتصال؛ `test-scene.mjs` يتحقق من الهندسة وربط المشهد بالحالة دون WebGL أو مصادر فعلية.
