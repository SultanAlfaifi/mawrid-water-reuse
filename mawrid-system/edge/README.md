# جامع مورد المحلي

جامع Python بالمكتبة القياسية فقط، يستقبل ملفات JSONL أو stdin ويحفظ القراءات في طابور SQLite قبل إرسالها إلى خادم مورد المحلي. لا يولّد قياسات، ولا ينشئ جلسات، ولا يتصل بعتاد أو نموذج ذكاء اصطناعي أو صمام. هذا مسار تحميل قراءات مقاسة أو ملفات اختبار موسومة.

## المدخل

كل سطر كائن JSON واحد يحتوي **فقط** على:

- `timestamp`: الطابع الأصلي بصيغة ISO8601 مع منطقة زمنية، مثل صيغة `YYYY-MM-DDTHH:MM:SS+03:00`. لا يستبدله الجامع بوقت الإرسال.
- `device_id`: هوية الجهاز الأصلية، نص غير فارغ حتى 100 محرف.
- `channels`: المفاتيح الأربعة كلها: `turbidity` بوحدة NTU، و`ph`، و`chlorine` بوحدة mg/L، و`flow_lpm` بوحدة L/min. كل قيمة عدد محدود أو `null` للفقد. التدفق السالب مرفوض.

تُرفض الحقول الإضافية، والقيم المنطقية أو النصية بدل الأرقام، وNaN/Infinity، والمفاتيح المكررة. لا يملأ الجامع القيم الناقصة. يجب اختيار `--input-kind measured` للقراءات المقاسة، أو `fixture` لملف اختبار، وعندها يجب أن تبدأ هوية الجهاز بـ`fixture-` أو `fixture:` حتى تبقى صفة الاختبار ظاهرة في سجل الخادم. يُحفظ نوع المدخل أيضًا في الطابور المحلي.

## التشغيل

أنشئ جلسة مصدر **قراءات جهاز عبر API** من التطبيق أولًا، ثم انسخ UUID الخاص بها. الجامع لا ينشئها أو يعيد ربط القراءات عند تبديل الجلسة. من جذر المشروع:

```sh
python3 -B mawrid-system/edge/main.py --database /absolute/path/outbox.sqlite3 ingest --session-id SESSION_UUID --input /absolute/path/readings.jsonl --input-kind measured
python3 -B mawrid-system/edge/main.py --database /absolute/path/outbox.sqlite3 status --session-id SESSION_UUID
python3 -B mawrid-system/edge/main.py --database /absolute/path/outbox.sqlite3 flush --session-id SESSION_UUID --once
```

استبدل `SESSION_UUID` بالقيمة الفعلية بحروف صغيرة؛ ليس المثال جلسة جاهزة. استخدم `--input -` للقراءة من stdin. قاعدة البيانات الافتراضية هي `edge/var/outbox.sqlite3` إن حُذف `--database`.

`ingest` يتحقق ويحفظ فقط، دون إرسال. `flush --once` يرسل حتى 1000 قراءة جاهزة بالترتيب، ويتوقف عند أول تأجيل أو خطأ. `flush --watch` يواصل مراقبة الطابور وإعادة المحاولة، ويمكن إيقافه بـCtrl-C. يمكن تشغيل `ingest` في عملية أخرى لإضافة قراءات إلى الجلسة نفسها. الوجهة محصورة في `127.0.0.1` والمنفذ الافتراضي 8787؛ يمكن تغيير المنفذ محليًا بـ`--port`، ولا تُتبع إعادة توجيه HTTP.

## الحفظ والإيصالات

يحصل كل قياس على `measurement_id` UUID ثابت عند حفظه، مع `session_id` المثبت. يحفظ SQLite البيانات والمعرّفات ونقطة استئناف الملف في معاملة واحدة، مع WAL و`synchronous=FULL`. لا يُعد القياس مُرسلًا إلا بعد إيصال يطابق معرّفي القياس والجلسة ويحتوي `reading_id` صالحًا. إذا حُفظ القياس في الخادم ثم ضاع الرد، يعاد الطلب بالهوية والمحتوى نفسيهما؛ يعيد الخادم الإيصال الأصلي دون إنشاء قراءة إضافية.

إعادة المحاولة بتأخير 1، 2، 4، 8، 16، 32، ثم 60 ثانية كحد أقصى، وموعدها محفوظ بين التشغيلات. مهلة الطلب الكلية 5 ثوانٍ. لا تتجاوز قراءة أحدث قراءةً سابقة معلّقة. توجد مهلة حجز محلية 15 ثانية لاستعادة إرسال انقطع قبل حفظ إيصال محلي.

أي `session_not_active` أو `idempotency_conflict` أو خطأ دائم آخر يوقف طابور تلك الجلسة، وتبقى القراءة محفوظة بحالة `blocked`. لا يحذف الجامع القياس ولا يغيّر جلسته تلقائيًا. بعد إعادة تشغيل خادم مورد قد تصبح الجلسة القديمة غير نشطة؛ تبقى إعادة طلب إيصال قديم محفوظ مقبولة، لكن قراءة جديدة للجلسة القديمة تُرفض حسب عقد الخادم. افحص الخطأ قبل أي إجراء يدوي؛ لا تغيّر المعرّفات لتجاوز التعارض.

ملف JSONL قابل للاستئناف باستخدام المسار والجلسة، وعدد البايتات، وبصمة SHA256 لكل الجزء المستهلك. إعادة تمرير الملف نفسه لا تكرر السطور المحفوظة. يجب ألا يتغير الجزء المستهلك؛ يسمح بإضافة سطور جديدة كاملة تنتهي بسطر جديد. يُرفض الملف المختصر أو ذو المقدمة المتغيرة. عند سطر غير صالح يتوقف الاستيراد وتبقى السطور السابقة محفوظة. لا يعدّل الجامع ملف المدخل.

ضمان الاستعادة يبدأ **بعد نجاح حفظ السطر**؛ بايتات stdin التي لم تُحفظ لا يمكن استعادتها تلقائيًا. أعد استخدام ملف محفوظ للاستيراد القابل للاستئناف، ولا تعِد ضخ stdin كاملًا بافتراض إزالة تكرار سطوره؛ إعادة الضخ عملية استيراد جديدة.

رموز الخروج: `0` نجاح، `75` إعادة محاولة أو انتظار أو بلوغ دفعة 1000، `3` طابور محجوب، `2` خطأ مدخل/حفظ، `130` إيقاف المستخدم. مخرجات JSON تعرض الحالة والمعرّفات والإيصالات دون قيم الحساسات.

## الاختبارات

```sh
python3 -B -m unittest discover -s mawrid-system/edge -t mawrid-system -v
```

تستخدم الاختبارات مدخلات مصطنعة واضحة، وSQLite مؤقتة وخادم HTTP مؤقتًا. لا تفتح قاعدة بيانات التطبيق أو أجهزة فعلية. قبول النقل لا يثبت جودة الماء أو كفاءة النموذج؛ قياسات هذا المخطط تستخدم قواعد التطبيق التجريبية، والذكاء الاصطناعي غير مؤهل لها حاليًا.
