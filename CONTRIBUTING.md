# Contributing

MAWRID welcomes engineering, water-quality, controls, data, safety, and design contributions.

## Evidence rules

- Label external findings as `LITERATURE` and cite the primary source.
- Label unmeasured acceptance criteria as `TARGET`.
- Use `RESULT` only with a method, sample size, uncertainty, and raw-data path.
- Keep simulated dashboard values explicitly labeled `SIMULATED`.
- Do not claim safety, compliance, certification, novelty, or cost leadership without appropriate evidence.
- Treat changes to release logic, disinfection, plumbing, or safety limits as safety-critical.

## Pull requests

Describe the problem, the proposed change, the evidence affected, and the verification completed. Do not commit confidential site information, personal data, credentials, or copyrighted papers.
