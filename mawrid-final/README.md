# مورد | MAWRID

صفحة عربية مستقلة لتصور وحدة استعادة مياه الوضوء ومغاسل اليدين. المجسم والواجهة مبنيان من الصفر. المقاس الافتراضي **M20**، والمقياس **1 وحدة = 1 متر**.

## التشغيل

```sh
npm install
npm run dev -- --host 127.0.0.1
```

للإنتاج: `npm run build`، ثم انشر مجلد `dist` على أي استضافة ملفات ثابتة. للمعاينة: `npm run preview`.

## تعديل المقاسات

كل أبعاد الأجزاء والمسافات موجودة في **`src/unitSpec.js`**، مع أصل كل مجموعة أبعاد في التعليقات:

- `presets.M10 / M20 / M30`: أبعاد المستخدم التجارية الاسمية، بالمتر.
- `common`: الأجزاء المشتركة بين الأحجام.
- `layout / detail / site / human / camera`: التفاصيل المقترحة ومواقع الوصول وبيئة العرض.
- `rendering`: قيم البكسل والأداء والزمن، وليست أبعادًا هندسية.

`src/components.js` هو مصدر الأرقام والرموز والبطاقات والجدول وCSV. الأسماء التجارية وشعارات المصنعين غير مستخدمة.

## قراءة التصور

أبعاد الخزانات الخارجية والسعات الاسمية من موجز المشروع؛ لا تمثل حجمًا هندسيًا صافيًا أو حجم تشغيل مضمونًا. مثال M20: الحيز الأسطواني الكامل بقطر 1.90 م وارتفاع 2 م ≈ 5.67 م³، ويختلف عن السعة الاسمية 5 م³ بسبب شكل الخزان والحيز الحر. يلزم تثبيت الشكل والسعة الفعلية مع المورد.

رؤوس FRP ضمن 2 م عند ارتكاز الأسطوانة على مستوى 0.09 م: أعلى رأس M20 = 0.09 + 1.651 + 0.22 = **1.961 م**. يعرض التصور قاعدة معدات منخفضة محمولة داخل قنوات الإطار، وصينية تسرب غائرة دون تصادم، وتحتاج تفاصيلها الإنشائية إلى تثبيت. ارتفاع الأسطوانة المعطى يشمل قاعدتها؛ لا تُضاف قاعدة ثانية إلى ارتفاعها.

خلوص الخدمة المعتمد لهذا التصور بحسب توجيه المستخدم: **0.90 م أمامًا، 0.60 م عند كل نهاية، 0.30 م خلفًا**. الصمامات والمانومترات والعينات والتحكم تواجه الأمام، وتوجد درجة خدمة قابلة للطي أمام المرشحات لتسهيل الوصول إلى الرؤوس المرتفعة. هذه الممرات خارج حدود الهيكل؛ عرض الهيكل المحدد لا يتيح خلوصًا شعاعيًا 0.6–0.8 م حول كل أسطوانة من جميع الجهات. لا يُفسر العرض المفكك بوصفه وضع تشغيل فعليًا.

يبقى فوق رؤوس الصمامات **0.50 م على الأقل** لخدمة الرأس، لذلك يُحصر مجرى الكابلات في الخلف أو الجانب ولا يمر فوق الأسطوانات. يلزم تثبيت مسار استخراج الأجزاء وارتفاع التركيب النهائي في التصميم التفصيلي. قيود التصميم نفسها متاحة للواجهة في `unitSpec.constraints`.

ألوان المواسير: رمادي للماء الخام والعملية، بنفسجي للماء المعالج، أسود للصرف. الحماية تعرض V-601 مغلقًا عند الخلل وانقطاع الطاقة. القراءات وحركة الماء تمثيل توضيحي؛ لا تثبت أداء المعالجة أو الجرعة الميكروبية أو مطابقة جودة المياه للري. اختيار المضخات، تدفقات الغسيل، وسط Biochar، جرعة UV، الحدود التشغيلية، أنابيب الصرف والكهرباء تحتاج حسابًا واعتمادًا منفصلين.

## اللقطات والجدول

التصدير يلتقط الوضع الحالي PNG بدقة 3840×2160، مع الوسم التوضيحي دائمًا. يتوفر CSV عربي بترميز UTF-8 مع BOM لفتحه في برامج الجداول. الصور الأربع المطلوبة في مجلد `deliverables`:

- `01-studio-4k.png`: نظرة عامة في الاستوديو.
- `02-section-4k.png`: المقطع الداخلي.
- `03-numbered-4k.png`: الترقيم وجدول المكونات والقيود الموثقة.
- `04-site-4k.png`: وضع الموقع.

الخامات الدقيقة مولدة إجرائيًا من Canvas؛ إضاءة البيئة مولدة بـ RoomEnvironment، ولا يتطلب العرض صور خامات أو HDRI خارجية. عند تعذر WebGL تظهر صورة بديلة. يحترم العرض `prefers-reduced-motion`.


## الأداء والفحص

المعاينة تعمل عند الطلب؛ تتوقف عن إعادة الرسم في النظرة العامة الساكنة أو عند خروج المشهد من الشاشة؛ تستمر حركة المراوح في زوايا المعدات القريبة. تُرسم اللقطة الساكنة بدقة 2× على الحاسب، وتُخفض أثناء السحب ثم تُستعاد. الجودة التلقائية تخفف المعالجة المكلفة، بينما يشغّل التصدير GTAO وSMAA وOutputPass وBloom الانتقائي بدقة 4K. خريطة الظلال 2048 في المعاينة الاقتصادية و4096 في الجودة العالية والتصدير. معدل 60/30 إطار هدف مرتبط بالجهاز وليس ضمانًا.

`npm run verify` يفحص الأبعاد والترقيم ونهايات مسارات المواسير والحماية وفجوة الصرف لكل حجم. `npm run build` يولد الموقع الثابت. تعتمد الصفحة Three.js **0.186.1** وVite **8.3.4**، مثبّتتين في package-lock.json. ترخيص Three.js في `public/licenses/three-MIT.txt`، والخط العربي المحلي IBM Plex Sans Arabic مرخّص وفق OFL في `public/licenses/IBM-Plex-Arabic-OFL.txt`. لا توجد HDRI خارجية تحتاج ترخيصًا آخر.

نسخة إضافية بخلفية شفافة: `deliverables/05-transparent-4k.png`. حزمة `MAWRID-delivery.zip` تضم المصدر والموقع المبني واللقطات والجداول دون node_modules.
