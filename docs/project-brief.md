# مرجع مشروع مورد · MAWRID

**مورد — مياه الوضوء، مورد للري. لا لتر بلا تحقق.**

مورد مشروع لاسترجاع مياه الوضوء والمغاسل المفصولة عن الصرف المختلط، ومعالجتها للاستخدام في ري مساحات خضراء محددة. يجمع مسار معالجة معروفًا، وحساسات لمراقبة التشغيل، وحماية مستقلة للمخرج، وسجلًا يميّز الماء المستخدم فعلًا عن الماء المجمع أو المحاكى.

**English:** MAWRID proposes source-separated ablution and washbasin water reuse for defined landscape irrigation, combining treatment, operational monitoring, independent outlet protection and traceable water accounting. The repository includes a public explanatory website and a working local software prototype. It does not establish physical treatment performance, field approval or a confirmed customer partnership.

## المنتج والعميل

| العنصر | التعريف الحالي |
|---|---|
| الوحدة الكاملة | محطة معالجة ومراقبة مقترحة لموقع مؤهل، مع تحديد الخزانات والأعمال المدنية والربط في نطاق العرض الفعلي |
| صندوق مورد | طبقة مراقبة وتحكم مقترحة لتحديث محطة قائمة؛ توافق الحساسات والصمامات والبنية الحالية يحتاج مسحًا هندسيًا |
| المصدر | مياه وضوء ومغاسل موصوفة ومفصولة؛ تُستبعد المراحيض والمطابخ والصرف المختلط، وأي مصدر إضافي يحتاج توصيفًا مستقلًا |
| الاستخدام | ري غير شربي في قطاع مضبوط وفق مراجعة المصدر والطلب والتعرض والمتطلبات المنطبقة؛ لا شرب أو وضوء أو تحضير غذاء |
| المستخدم | مشغل المحطة أو فني المرافق؛ يحتاج متابعة واضحة وتنبيهًا قابلًا للتصرف |
| العميل وصاحب القرار | جهة تملك أو تشغل موقعًا مؤهلًا، ومنها المؤسسات الأكاديمية؛ تُثبت الحاجة والصلاحيات ومسار الشراء لكل موقع |
| القيمة المراد إثباتها | ماء مسترجع استُخدم فعلًا، تشغيل قابل للمراجعة، وصيانة وتكلفة يمكن مقارنتهما بخط أساس |

لا توجد شراكة أو موافقة جامعة أو موقع ميداني معتمد موثق. كانت العابدية وفروع أم القرى موضوع دراسة وترشيح سابقين؛ لا تمثل تلك الدراسة التزامًا أو حصرًا للنسخة التنفيذية الحالية.

## مرجعية النسخة الحالية

يعكس هذا التحديث توجيه صاحب المشروع باعتماد مرجع المحطة HTML الأحدث في التفاصيل التقنية والتنفيذية والتسعيرية عند تعارضه مع الوصف الكامل السابق. حُفظت هنا خلاصة مواصفات المشروع فقط؛ المرفق الخاص وعرض المورد الذي يستند إليه لا يُعاد نشرهما في المستودع.

تتقدم مواصفات النسخة الحالية أدناه على قرارات الدراسة السابقة ذات سعة 20 م³/يوم، وافتراض استرداد 80%، وإلزام فحم النخيل في المسار الأساسي. ليست تلك القرارات مواصفات المحطة المحاكية الحالية. الأرقام التالية `DESIGN`، وليست قياسات أو ضمانات:

| البند | مرجع التصميم الحالي وحده |
|---|---|
| التدفق | 1,000 لتر/ساعة؛ 15 م³/يوم عند 15 ساعة تشغيل، دون جدول يومي آلي منفذ |
| الخزان الخام | 5 م³، GRP مصمم للدفن؛ اختيار المنتج والتثبيت والطفو يحتاج اعتمادًا هندسيًا |
| خزان المنتج | 5 م³، بولي إيثيلين أفقي فوق الأرض |
| الكربون | كربون نشط تجاري في الأساس؛ فحم مخلفات النخيل بحث إحلال لاحق مشروط بالاختبار |
| الجرعات | أربع نقاط مستقلة: كلور أولي، SMBS لإزالة الكلور، مادة متوافقة للروائح أو تعديل pH، وكلور نهائي |
| UV | موضع حاجز إضافي اختياري؛ إدراجه ومواصفته يعتمدان على التحقق ونطاق العرض |
| الغسيل | مرجع تدفق تقريبي 65 لتر/دقيقة، يحتاج منحنى مضخة وصمامات ومخزونًا كافيًا؛ المحاكاة تقيده بالماء المتاح |
| الفواقد والعودة | لا RO أو رفض اعتيادي مفترض بنسبة 20%؛ تُقاس مياه الغسيل والتحويل والفائض. فرع العودة تصميمي وتدفقه صفر في التوأم الحالي |

أي حدود جودة أو أسعار في مواد الدراسة تبقى مدخلات مراجعة لا اعتمادًا أو عرض بيع ملزمًا. لا تثبت واجهة البرنامج كفاءة الجرعات أو إزالة الملوثات أو صلاحية الري.

## رحلة الماء

**فصل المصدر ومصفاته → الخزان الخام والضخ → كلورة أولية → وسائط متعددة → إزالة كلور وقياس ORP → كربون تجاري → خراطيش دقيقة → روائح/pH وكلورة نهائية → التحقق من شروط التشغيل → UV اختياري → خزان المنتج → الري.**

يظهر مسار الاحتجاز والتحويل مستقلًا عن الاستخدام. تراقب الحساسات التشغيل؛ تتحقق الطرق المخبرية من جودة الماء للغرض المقصود. لا يستنتج الكلور الحر من ORP، ولا تثبت العكارة وحدها غياب الميكروبات. الذكاء ينبّه أو يوصي بالاحتجاز، ولا يمنح صلاحية فتح المخرج.

## ما يوجد اليوم

| الجزء | الدليل والحدود |
|---|---|
| الموقع العام | قصة بالعربية والإنجليزية، ومستكشف ومحاكي تعليمي ثابت؛ يعمل دون الخدمة المحلية |
| النظام المحلي | خدمة Python وSQLite، وتوأم افتراضي، وسجل وواجهات تصدير، ومجسم يقرأ لقطات المحرك |
| رحلة العرض UX V8 | ثماني مراحل تلقائية مع تقريب الكاميرا، وإيقاف ومتابعة يحفظان وقت القراءة؛ لا يحقن العرض عطلًا تلقائيًا |
| المعالجة والحماية المادية | تصميم وخطة تحقق؛ لا محطة أو اختبار صمام أو نتائج مياه ميدانية مثبتة بهذه البرمجيات |
| بحث الذكاء | نماذج مدربة ومقيمة على بيانات عامة؛ V9 متصل بإعادة عرض بحثية مؤهلة فقط. لا يعمل ML على ماء التوأم أو مخطط قراءات الجهاز |
| فحم النخيل | تجربة مستقبلية مقابل الكربون التجاري، دون نتائج أداء أو عمر أو نضّ أو جدوى مثبتة |
| السوق والتسعير | فرضيات وتقديرات تحتاج عروضًا وقياس طلب وتكلفة ملكية؛ لا بيع أو وفر أو شراكة مؤكدة |

تسجل [بطاقة النموذج](data-and-model-card.md) النتائج الحقيقية وحدودها؛ هدف الاحتفاظ بكل الأحداث مع تقليل الإنذارات لم يتحقق. نجاح الاختبارات البرمجية لا يثبت قبول النموذج ميدانيًا أو سلامة الماء.

## التحقق قبل الانتقال الميداني

1. اختيار موقع بمصدر مفصول وطلب ري معلوم؛ قياس الخط الأساس والبدائل والموافقات المطلوبة.
2. تثبيت مخطط المعدات والطرق المخبرية و3–5 مؤشرات قبول ومخاطر قبل الاختبار.
3. اختبار مسار الكربون التجاري والتعقيم والتخزين أولًا؛ دراسة النخيل منفصلة ولا تحل محل حاجز تعقيم مثبت.
4. اختبار المتحكم والصمام والطاقة والحساسات ماديًا، مع تسجيل الأمر والموضع والتدفق كلٍّ على حدة.
5. مقارنة الماء المستخدم والتكلفة والصيانة بخط أساس مماثل، ثم اتخاذ قرار تجربة ميدانية محددة النطاق.

تفصل [خطة التحقق](validation.md) و[تصميم النظام](system-design.md) هذه البوابات. توضح [خريطة المخرجات](judging-map.md) التسليمات التسعة والفجوات؛ لا تعني جاهزية العرض اكتمال المشروع المائي.

## قياس القيمة دون خلط

نميّز الماء المسترجع المستخدم للري عن إزاحة مياه الشرب. الإزاحة الصافية تحتاج مصدر الري السابق وطلبًا مماثلًا واحتساب مياه الشرب الإضافية للمعالجة والغسيل. تُعرض أحجام التجميع والري والغسيل والتحويل والفائض والتخزين منفصلة، ولا تُخصم الفواقد مرتين. [الأثر والتكلفة](impact-and-economics.md) يحدد إطار الحساب.
