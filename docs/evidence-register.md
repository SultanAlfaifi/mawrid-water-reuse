# سجل أدلة مورد

يرجع هذا السجل إلى [مرجع المشروع](project-brief.md). دوره بيان ما يمكن إثباته من المستودع وما يحتاج تجربة؛ يُحدَّث بعد ظهور دليل قابل للفحص، ولا يرفع الادعاء إلى نتيجة بسبب اكتمال تصميم أو واجهة.

## وسوم الدليل

| الوسم | المعنى | مثال استخدام صحيح |
|---|---|---|
| `DESIGN` · تصميم | قرار نطاق أو تصميم موثق | الري غرض النسخة الأولى المقترح |
| `SIMULATED` · محاكاة | بيانات أو مدخلات مصطنعة لاختبار العرض والبرمجيات | فقد حساس في التجربة الرقمية |
| `ILLUSTRATIVE` · توضيحي | شكل أو حساب أو مثال لشرح الفكرة | الشكل ثلاثي الأبعاد، ومثال تكلفة افتراضي |
| `TARGET` · هدف | معيار قبول معلن قبل الاختبار | استرداد مقترح في بروتوكول التجربة |
| `LITERATURE` · مرجع | ما تقوله دراسة أو جهة خارجية | دراسة منشورة عن امتزاز مادة نخيل |
| `RESULT` · نتيجة | قياس لمورد مرتبط ببيانات خام وطريقة ومعايرة وشروط اختبار | سجل تجربة مائية موثق؛ لا يوجد حاليًا في المستودع |
| `NOT TESTED` · لم يُختبر | فرضية أو أداء ينتظر دليلًا | عمر خرطوشة مورد وتكلفة التشغيل في الموقع |

## المواد الموجودة

| الرمز | المادة | الوسم | ما تثبته وما لا تثبته |
|---|---|---|---|
| E01 | [مرجع المشروع](project-brief.md) | `DESIGN` | يحدد المصدر والعميل والاستخدام؛ لا يثبت طلبًا مقاسًا أو موافقة موقع |
| E02 | [تصميم النظام](system-design.md) و[الحماية](safety.md) | `DESIGN` | يشرحان المكونات والحواجز المستهدفة؛ لا يثبتان تنفيذها المادي |
| E03 | [المستكشف التعليمي](../index.html) و[سيناريوهات العرض](demo-scenarios.md) | `ILLUSTRATIVE` / `SIMULATED` | يشرحان المسار وسلوك القواعد تحت مدخلات محاكاة؛ لا يتحققان من معالجة ماء أو صمام مادي |
| E04 | [عينة الحساسات](../data/sample-telemetry.csv) | `SIMULATED` | مثال بيانات موسوم؛ لا بيانات من حساس مورد فعلي |
| E05 | [مخطط الحساسات](../data/sensor-data-schema.csv) و[مخطط المطابقة المخبرية](../data/laboratory-results-schema.csv) | `DESIGN` / `SIMULATED` | يصفان حقول التتبع؛ الصف التوضيحي لا يثبت مطابقة قياس |
| E06 | [خطة التحقق](validation.md) | `DESIGN` / `TARGET` | تحدد التجارب والأهداف المقترحة؛ لا تقرير نتائج |
| E07 | [المراجع](../references/README.md) | `LITERATURE` | أساس علمي وتقني خارجي؛ لا نتائج لمادة أو مياه مورد |
| E08 | [خريطة المخرجات](judging-map.md) | `DESIGN` | مطابقة تنظيمية وحالة فجوات؛ لا درجات تحكيم أو إعلان اكتمال التسليم |

## الادعاءات وبوابات إثباتها

| الرمز | الادعاء الذي نريد اختباره | الحالة الحالية | الدليل المطلوب |
|---|---|---|---|
| C01 | توجد مياه وضوء وطلب ري متزامنان في الموقع | `NOT TESTED` | قياسات المصدر والطلب والتخزين ومخطط الفصل، ومراجعة موسمية |
| C02 | المعالجة تحقق متطلبات استخدام الري المختار | `NOT TESTED` | نتائج بطرق مخبرية مناسبة، وعينات وتكرارات وضوابط، ومراجعة متطلبات الاستخدام |
| C03 | الجهاز المادي يحول الماء عند الأعطال المعلنة | `NOT TESTED` | سجل عطل ومدخلات واستجابة صمام ومتحكم فعلي، بما فيها فقد الطاقة |
| C04 | فحم النخيل يضيف قيمة أمام البدائل | `NOT TESTED` | مكوّن مستهدف ومقارنة متكافئة وأداء، وما قد تطلقه المادة إلى الماء، وعمر وكلفة |
| C05 | قواعد الصيانة تخفف العمل أو الاستبدال غير اللازم | `NOT TESTED` | قياس تدخلات ووقت المشغل وعمر الوسائط أمام خط أساس واضح |
| C06 | مورد يعوض مياه شرب في الري | `NOT TESTED` | خط أساس مصدر الري، وطلب مماثل، وماء مسترجع مستخدم، وأي ماء شرب إضافي للعملية |
| C07 | العميل مستعد لتبني تجربة أو شراء المنتج | `NOT TESTED` | مقابلة موثقة أو خطاب اهتمام أو عرض مقبول؛ كل نوع دليل يوصف باسمه |
| C08 | التكلفة والتوسع التجاري مقبولان | `NOT TESTED` | عروض أسعار وتكلفة ملكية وموارد دعم ومواقع مناسبة وعد موثق |
| C09 | AI يقدم فائدة إضافية | `NOT TESTED` | بيانات ممثلة ونموذج وخط أساس وتقييم مستقل قبل إدخاله للتشغيل |

لا توجد شراكة أو موافقة مؤكدة موثقة في هذا السجل. لا يوجد سجل نتائج مائية `RESULT` حاليًا. المؤشرات الرقمية في [بروتوكول التحقق](validation.md) أهداف تجريبية، وليست حدودًا تنظيمية أو إنجازات لمورد.

## متطلبات إضافة نتيجة

تتضمن النتيجة رقم البروتوكول وإصداره، ورقم العينة والدورة، ومصدر الماء وشروطه وزمن تخزينه، واسم الطريقة ووحدتها وحدود قياسها، والجهاز وحالة معايرته، والقراءات الخام، وضوابط الجودة، والتكرارات والاستبعادات مع أسبابها، وتاريخ الاختبار، والحدود التي تسري عليها النتيجة.

نتيجة في مادة أو دورة أو موقع لا تعمم تلقائيًا على مواد أو مواقع أخرى. تقرير فشل أو نتيجة غير حاسمة يبقى دليلًا مفيدًا ويؤدي إلى تعديل أو إيقاف المسار. تحفظ بيانات التواصل والموافقات والمرفقات الخاصة خارج المستودع العام؛ ينشر وصف منقح للدليل فقط بعد السماح بذلك.
