# تجربة مورد المباشرة للمحكّم

المسار المنشور: [`/experience/`](../experience/). صفحة ثابتة تعمل داخل المتصفح، مع مشهد المحطة الأصلي وقواعد تشغيل افتراضية. لا تتطلب Python أو حسابًا أو خادم API.

## تجربة قصيرة

1. شغّل المحاكاة، ثم شاهد مسار الماء أو ابدأ الجولة.
2. اختر «ارتفاع العكارة» أو «انقطاع قراءة حساس»: يتوقف تدفق الري ويظهر سبب الاحتجاز، ويغلق الصمام الافتراضي.
3. اختر «تشغيل طبيعي» لمشاهدة استعادة القاعدة الافتراضية. «تعطل صمام الري» يفصل طلب الفتح عن تأكيد الموضع المغلق.
4. أوقف الساعة أو أعد البدء. يمكن فتح السجل وتنزيل JSON يحمل مصدر البيانات وحدودها وحالة الساعة.

## ماذا يعمل وما حدوده؟

- المشهد يعيد استخدام `mawrid-system/plant3d/scene.js` وملفات رحلة الماء والكاميرا دون تعديلها. الضغط على مكوّن يعرض اسمه، وأزرار المراحل تحرك الكاميرا وتظلل المسار.
- `experience/src/model.js` نقل محدود لقواعد `mawrid-system/server/plant.py` إلى JavaScript: نفس الإشارات الافتراضية، حدود تجريبية ثابتة، حالات احتجاز، فصل أمر الصمام عن تأكيده، وميزان ماء للخزانين. هذه تجربة برمجية، وليست نموذج معالجة كيميائية أو تقديرًا لصلاحية الماء.
- جميع القراءات مولّدة داخل المتصفح. لا طلبات `/api`، ولا SQLite، ولا اتصال عتاد، ولا بيانات GECCO أو نموذج تعلم آلي مستخدم في هذه الصفحة. النظام المحلي الكامل وأدلته باقية في مجلدها الأصلي.
- السرعة تضاعف مرور الساعة الافتراضية فقط. التوقف المؤقت يجمّد الزمن ويوقف حركة التدفق؛ يبقى آخر موضع افتراضي للصمام، ويُعرض قرار القاعدة عند التشغيل منفصلًا عن التدفق الصفري أثناء التوقف.
- السجل في ذاكرة الصفحة، بحد 250 حدثًا؛ لا حفظ دائم أو مشاركة بين الأجهزة. إعادة البدء تصفره. مغادرة الصفحة توقف المحاكاة. ملف JSON يبين `simulation_running` و`clock_paused` والتدفقات الفعلية داخل المحاكاة، ويشرح أن معدلات `snapshot` تصف القاعدة الآنية حتى عند إيقاف الساعة.
- سعة التغذية 1,000 لتر/ساعة، أي 15 م³ خلال 15 ساعة، افتراض تصميمي. الخزانان 5 م³ لكل منهما. لا دورة تشغيل يومية مفروضة أو استهلاك مبنى مقاس. الغسيل العكسي في المحرك محدود بالمخزون، وخط الإعادة وUV والجرعات تفاصيل تصميمية دون فعالية محسوبة.
- يدعم WebGL، وأزرار لوحة المفاتيح، وتقليل الحركة، والجوال. إذا تعذر WebGL تظل أدوات المحاكاة والقراءات متاحة برسالة واضحة.

## المصادر والبناء

المصادر: `experience/src/`. الناتج الذي تنشره GitHub Pages: `experience/index.html` و`experience/assets/`، بروابط نسبية تعمل أيضًا تحت `/mawrid-water-reuse/experience/`.

من جذر المستودع وبعد توفر الاعتماديات المقفلة الموجودة أصلًا:

```powershell
node experience/build.mjs
node --test experience/test-model.mjs
python -m http.server 8894 --bind 127.0.0.1
```

يمكن تمرير مسار مجلد `node_modules` الموجود كوسيط أول للبناء. لا تثبيت أو تنزيل أثناء هذا الأمر. يستبدل البناء ناتج `experience/assets/` و`experience/index.html` فقط؛ لا يزيل المصادر أو النظام الأصلي أو الأدلة والنسخ القديمة.

## التحقق

اختبار التكافؤ يشغّل مرجع Python ويقارن 74 لقطة تمثيلية: الحالة الطبيعية والأعطال الخمسة، والتعافي، والاستعداد، والغسيل حتى نفاد المخزون، والإيقاف اليدوي، وسرعات الساعة. المقارنة تشمل القنوات وصلاحيتها، والأحجام، والتدفقات، والمضخات والصمام، وحالات وأسباب القرار، بتسامح عددي `1e-8`. يختلف `source` عمدًا إلى `browser_simulation`. وتوجد اختبارات مستقلة للاحتجاز، والقراءة المفقودة، واختلاف أمر/تأكيد الصمام، وميزان الماء خلال تسلسل طويل، ورفض المدخلات غير الصالحة.

هذه الاختبارات تتحقق من توافق النقل وسلامة الحسابات المحدودة. لا تتحقق من مياه فعلية أو عتاد أو سلامة تشغيل ميداني، ولا تحول العتبات التجريبية إلى حدود معتمدة.
