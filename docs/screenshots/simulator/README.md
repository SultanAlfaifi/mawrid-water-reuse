# لقطات محاكي مورد — SIMULATED

هذه صور من تشغيل المتصفح المحلي للنسخة نفسها، وليست صور جهاز مائي أو نتائج قياس. لم تُعدل الصور أو تُركب الأرقام عليها. يظهر شريط الإفصاح في اللقطات الثلاث.

| الملف | الحالة وطريقة إعادة العرض |
|---|---|
| [01-normal.jpg](01-normal.jpg) | الإعدادات الافتراضية، جامع كبير، بذرة 350. ست ضغطات «تقدم ساعة» = الخطوة 72، الأحد 06:00. تصريح الري صادر من القواعد. |
| [02-fault-hold.jpg](02-fault-hold.jpg) | من الحالة السابقة: حقن انحراف حساس العكارة عند الخطوة 72، ثم «تقدم ساعة» إلى الخطوة 84. افتح «التشغيل الحي»: الاحتجاز مقفول حتى المعايرة الافتراضية. |
| [03-comparison.jpg](03-comparison.jpg) | من الحالة السابقة: حقن انقطاع الكهرباء عند الخطوة 84 دون تقدم الزمن، ثم فتح «المقارنة». نفس التدفق والأعطال لمورد والترشيح البسيط؛ Hydraloop تحجيم منشور فقط. |

ملف [checks.json](checks.json) ملخص قابل لإعادة الإنتاج لأسبوع كامل: السيناريو الافتراضي ثم كل عطل منفردًا عند الخطوة 150، ببذرة 350. يختلف عن نافذة لقطات الشاشة أعلاه. جميع المخرجات `SIMULATED`؛ جودة الماء الحقيقية المفترضة تفحص المخرجات بعد قرار المتحكم. الاختبارات الكاملة في `tests/simulator.test.mjs`.

فُحصت الواجهة في المتصفح بعرض ضيق يقارب 388 بكسل CSS دون تجاوز أفقي للصفحة؛ المخطط الواسع والجداول يتمرران داخل حاوياتهما. تأكد تحميل الخط العربي، وحارس `prefers-reduced-motion`، والإغلاق الفوري عند حقن فقد الطاقة، وعرض مسودة التقرير. لم تظهر أخطاء أو تحذيرات في سجل المتصفح للصفحة.

التوازن الرقمي وعدّاد التجاوزات لا يثبتان دقة عداد أو سلامة صمام مادي. راجع [حدود النموذج](../../simulator-model.md) و[سيناريو العرض](../../demo-script.md).
