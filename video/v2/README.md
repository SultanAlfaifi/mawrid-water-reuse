# مورد — رحلة القرار

فيلم جديد مدته دقيقة، Full HD بمعدل 30 إطارًا/ثانية، بلا صوت وفق اختيار صاحب المشروع. المصدر قابل للتحرير في `src/`، والخطوط والهوية من أصول مورد المرخصة.

هذه معالجة سينمائية للمجسم البرمجي الأصلي: مشهد كامل، وإضاءة استوديو، ولقطات مصممة للخزان والمرشحات ولوحة القياس والصمام، مع حركة عربية للعبارات. لا توجد شرائح تسجيل شاشة أو توليد صور لمحطة منفذة.

يستخدم الفيلم `createVirtualScene` و`BrowserPlant` الأصليين. فقد قراءة الكلور عند الثانية 31 ينتج `HOLD` وصمامًا افتراضيًا مغلقًا وتدفق ري صفرًا؛ تعود الحالة الطبيعية عند الثانية 44. هذه قصة اختبار محاكاة وليست توقيت استجابة عتاد أو رحلة جزيء ماء. الأحجام والقراءات افتراضية، والألوان والأسهم والإضاءة وسائل شرح لا قياسات أو حساب فعالية معالجة.

## إعادة الإنتاج

تستخدم الأوامر الاعتماديات المقفلة الموجودة أصلًا في الجذر؛ لا تثبت أي حزم تلقائيًا:

```sh
node video/v2/build.mjs
node video/v2/render.mjs --stills
node video/v2/render.mjs --verify
node video/v2/render.mjs
```

يلزم Playwright مع Chromium مثبت مسبقًا، وFFmpeg على PATH؛ يمكن تعيين مسارهما في `MAWRID_PLAYWRIGHT_MODULE` و`MAWRID_FFMPEG`. تستخدم نسخة Windows مسار ANGLE/D3D11 المتاح. `.build/` و`.render/` وسائط مؤقتة يتجاهلها Git.

الفيلم النهائي: [mawrid-cinematic-demo.mp4](../../assets/demo/mawrid-cinematic-demo.mp4). النسخة الأولى ومصادرها وأدلتها باقية دون تغيير في `video/` و`assets/demo/mawrid-software-demo.mp4`.

## الفحص

نجح الاختبار القصير قبل إخراج الفيلم الكامل. يفحص `--verify` إعادة رسم خمس لحظات بعد القفز الزمني؛ تطابقت بصمات الصور تمامًا، مع سلامة حدود النص العربي واستجابة العطل الافتراضي. [فحص الوسائط](review/media-check.json) يفك الترميز كاملًا ويتحقق من 1800 إطار و60 ثانية و1920×1080 و30fps وغياب الصوت. [سجل المراجعة](review/review.md) يحدد نطاق الفحص البصري؛ لا يُعد فك الترميز مراجعة بصرية للحركة.
